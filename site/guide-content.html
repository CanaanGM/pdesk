What pdesk does

Windows already has virtual desktops. But one switch changes every screen at once. pdesk gives each screen its own set of workspaces. You switch only the screen under your mouse.

Windows' own desktopspdesk
  • Windows stay floating, as they normally are. pdesk never tiles or moves them around.
  • It only hides and shows windows. Nothing is closed when you switch.
  • Your layout is saved, so a restart of pdesk keeps every window on its workspace.

Words used here

Workspace

One set of windows on one screen. Each screen has 4 by default.

Hidden window

A window on a workspace you are not looking at. It still runs; you just cannot see it.

Tray

The small icons at the right end of the taskbar, near the clock.

UAC prompt

The Windows box that asks "Do you want to allow this app to make changes?".

Rust

The programming language pdesk is written in. You need it to build pdesk.

Steps

How do I install it?

The easy way needs nothing but Windows 11:

  1. Download the newest pdesk-…-windows-x64.zip from Releases.
  2. Unzip it. Open a terminal in the unzipped folder.
  3. Run the install script: 
    powershell -ExecutionPolicy Bypass -File install.ps1
  4. Say Yes to the UAC prompt. When the pdesk icon shows in the tray, pdesk is running.

To update, do the same with the newer zip. Your workspaces are kept.

Or build it yourself

You build pdesk on your own PC, then the same script installs it. You need three things:

The script does these steps for you:

  1. Build pdesk
  2. Ask for admin once
  3. Copy to Program Files
  4. Start at every sign in
  5. Start it now
Why does it need admin? When an admin window (like Task Manager) is in front, Windows stops normal apps from hearing the keyboard. As admin, pdesk hears its shortcuts everywhere.

To update pdesk later, get the new code with git pull and run the same install command again. Your workspaces are kept.

Shortcuts

Every shortcut works on the screen under your mouse.

KeysWhat it does
Win+Ctrl+Left / RightGo to the previous or next workspace
Win+1 … Win+9Go straight to workspace N
Win+Ctrl+Shift+Left / RightSend the window in front to the previous or next workspace, and go with it
Win+Ctrl+Alt+Left / RightSend it there, but stay where you are
Win+Shift+1 … 9Send the window in front to workspace N, and go with it
Win+Ctrl+1 … 9Send it to workspace N, but stay
Win+Shift+Left / RightMove a window to another screen (this one comes from Windows)
Win+FOpen the finder
Win+TabOpen the overview

After each switch, a small row of dots shows for a moment. It tells you which workspace you are on.

pdesk takes two Windows shortcuts. Win+Tab no longer opens Task View. Win+1 … 9 no longer open taskbar apps. You can change this in the settings.

Find any window

Press Win+F and type part of a window's name or its app. Windows you used last come first. It searches every screen and every workspace.

Ctrl+WClose the window

Press Win+Tab. Every screen shows all its workspaces at the same time, with live pictures of the windows.

Steps

Switch with the touchpad

A four finger swipe can switch pdesk's workspaces. You set it up once in Windows:

  1. Open Settings → Bluetooth & devices → Touchpad → Advanced gestures.
  2. Set the four finger swipe left to the custom shortcut Win+Ctrl+Right.
  3. Set the four finger swipe right to Win+Ctrl+Left.

Swap the two if the other way feels more natural to you.

Settings

Right click the pdesk icon in the tray, then Open settings. The file is %LOCALAPPDATA%\pdesk\settings.toml. Each line has a comment that says what it does.

[indicator] enabledtruetrue, falseThe row of dots after a switch
[indicator] hold_ms5500 to 5000How long the dots stay, in milliseconds
[indicator] fade_ms2000 to 2000How long the dots take to fade
[restore] enabledtruetrue, falseAfter a restart, put reopened windows back on their workspaces

[overview] labels"hover""hover", "always", "none"When the overview shows window titles

pdesk reads the file once, when it starts. After you edit it, run install.ps1 again, or sign out and back in.

A typo cannot break pdesk. A bad value only sets that one setting back to its default. The log says which one.

Good to know

  • A hidden window leaves the taskbar and Alt+Tab, so each screen shows only what is on it. Admin windows, like Task Manager, still show in Alt+Tab.
  • When a hidden window comes to the front by itself, pdesk switches its screen to that workspace.
  • After a restart of the PC, pdesk puts reopened windows back where they were, for the first 3 minutes after sign in.
  • The tray icon menu has Open settings, Open log and Quit.

Steps

Stop or remove pdesk

To stop it, click Quit in the tray menu. Every hidden window comes back, so nothing is lost. pdesk also forgets which window was on which workspace.

To remove it completely:

  1. Quit pdesk from the tray.
  2. Open a terminal as administrator and run: 
    Unregister-ScheduledTask -TaskName pdesk -Confirm:$false
Remove-Item -Recurse "$env:ProgramFiles\pdesk"
  3. If you also want your settings and log gone, delete the folder %LOCALAPPDATA%\pdesk.

For developers

Build and run from the code

Only one pdesk runs at a time. Quit the installed one first, or the second one says pdesk is already running and stops.

CommandWhat it does
cargo buildBuild a debug copy. It keeps a console window, so you see the log.
cargo runBuild and run it. Ctrl+C shows every hidden window and stops it.
cargo testRun the tests
powershell -File install.ps1Build the release copy and install it, as above
